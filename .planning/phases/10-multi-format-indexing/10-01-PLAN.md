  <name>Task 1: PDF chunker with pdfjs-dist</name>
  <files>src/lib/pdf-chunker.ts, src/lib/__tests__/pdf-chunker.test.ts</files>
  <behavior>
    - Test: Multi-page PDF buffer produces one chunk per page with sectionPath "filename > Page N"
    - Test: Page with >500 tokens is split at paragraph boundaries (double newline)
    - Test: Page with <10 tokens (headers/footers from scans) is skipped
    - Test: Scanned PDF (all pages empty text) returns zero chunks
    - Test: PDF metadata (title, author, subject) is extracted from document info
    - Test: Empty buffer or corrupt PDF returns zero chunks without throwing
  </behavior>
  <action>
Install pdfjs-dist: `pnpm add pdfjs-dist`

Create `src/lib/pdf-chunker.ts`:

1. `extractPdfPages(buffer: Buffer): Promise<{ pages: PdfPage[]; metadata: PdfMetadata }>` — Uses `pdfjs-dist/legacy/build/pdf.mjs` with `GlobalWorkerOptions.workerSrc = ''` for server-side usage. Iterates `doc.getPage(n)` -> `page.getTextContent()` -> joins `item.str` values. Returns page objects with pageNum (1-based), text, tokenCount.

2. `chunkPdf(buffer: Buffer, filename: string): Promise<Array<{ text: string; sectionPath: string; chunkIndex: number }>>` — Calls extractPdfPages, filters pages with <10 tokens (MIN_PAGE_TOKENS), splits pages >500 tokens at paragraph boundaries (double newline `\n\n`), assigns sectionPath = `"${filename} > Page ${pageNum}"`, assigns sequential chunkIndex across all pages.

Export interfaces: `PdfPage { pageNum: number; text: string; tokenCount: number }`, `PdfMetadata { title?: string; author?: string; subject?: string }`.

Use `getEncoding('cl100k_base')` from js-tiktoken for token counting (same as chunker.ts).

For paragraph splitting of large pages: split on `\n\n`, accumulate paragraphs until exceeding 500 tokens, then start a new sub-chunk. Each sub-chunk gets the same sectionPath.

Create `src/lib/__tests__/pdf-chunker.test.ts`:
- Use vitest mock to mock `pdfjs-dist/legacy/build/pdf.mjs` — don't load real PDF.js in tests
- Mock `getDocument()` to return a doc with configurable pages
- Test all behaviors listed above
  </action>
  <verify>
    <automated>pnpm test -- --run src/lib/__tests__/pdf-chunker.test.ts</automated>
  </verify>
  <done>PDF chunker extracts text by page, applies 10-token minimum filter, splits at 500 tokens, returns chunks with "filename > Page N" sectionPath. All tests pass.</done>
</task>
