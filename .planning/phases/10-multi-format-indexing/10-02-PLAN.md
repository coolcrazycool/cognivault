<!-- Canvas JSON 1.0 spec (from jsoncanvas.org/spec/1.0) -->
```typescript
interface CanvasFile {
  nodes: Array<{
    id: string;
    type: 'text' | 'file' | 'link' | 'group';
    x: number; y: number; width: number; height: number;
    text?: string;   // Only present on type='text'
    color?: string;
  }>;
  edges?: Array<unknown>;
}
```

<!-- Excalidraw JSON (from excalidraw deepwiki docs) -->
```typescript
interface ExcalidrawFile {
  type: 'excalidraw';
  version: number;
  elements: Array<{
    id: string;
    type: string;  // 'text', 'rectangle', 'arrow', etc.
    text?: string; // Only present on type='text'
    x: number; y: number;
    width: number; height: number;
    isDeleted?: boolean;
  }>;
}
```

    - Test: Non-text elements (rectangle, arrow, ellipse) are skipped
    - Test: Deleted elements (isDeleted: true) are skipped
    - Test: Very short text elements (<5 tokens) adjacent to each other are merged into one chunk
    - Test: Empty text elements are skipped
    - Test: Invalid JSON returns zero chunks without throwing
    - Test: File with no text elements returns zero chunks

  <action>
Create `src/lib/excalidraw-chunker.ts`:

`chunkExcalidraw(content: string, drawingName: string): Array<{ text: string; sectionPath: string; chunkIndex: number }>` — JSON.parse the content, validate it has an `elements` array, filter elements where `type === 'text'` AND `isDeleted !== true` AND `text` field is non-empty after trim.

For merging short elements: collect qualifying text elements in order. Walk through them — if a text element has fewer than 5 tokens AND the next element also has fewer than 5 tokens, merge their text with a newline separator. Continue merging until the accumulated text exceeds 5 tokens or there are no more short elements. Each merged group or standalone element becomes one chunk.

Assign:
- `text`: the element's text field (or merged text)
- `sectionPath`: `"${drawingName} > Text ${textNumber}"` (1-based, counting output chunks)
- `chunkIndex`: sequential from 0

Use type guards for Excalidraw JSON. Wrap JSON.parse in try/catch — return empty array on parse failure.

Use js-tiktoken `getEncoding('cl100k_base')` for the short-element merge threshold (same encoder as chunker.ts).

Create `src/lib/__tests__/excalidraw-chunker.test.ts`:
- Construct Excalidraw JSON strings directly in tests
- Test all behaviors listed above
