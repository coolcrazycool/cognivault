  <behavior>
    - resolveWritePath("notes/new.md") returns absolute path without requiring file to exist
    - resolveWritePath("../escape.md") throws PathTraversalError
    - resolveWritePath(".hidden/file.md") throws DotfileAccessError
    - resolveWritePath("") throws PathTraversalError (empty path)
    - createNote("new.md", "content") creates file on disk, returns { path, created: true }
    - createNote("existing.md", "content") throws FileExistsError (409)
    - createNote("deep/nested/note.md", "content") auto-creates directories
    - createNote("note.md", "body", { title: "T" }) writes YAML frontmatter block via gray-matter.stringify
    - createNote("note.md", "body") without frontmatter writes content with trailing newline, no --- block
    - updateContent("existing.md", "new content") replaces file content, returns { path, updated: true }
    - updateContent("missing.md", "content") throws FileNotFoundError
    - appendContent("existing.md", "extra", "append") adds text after existing content
    - appendContent("existing.md", "extra", "prepend") adds text before existing content
    - appendContent on file with frontmatter preserves the frontmatter block
    - appendContent("missing.md", "text", "append") throws FileNotFoundError
    - atomicWrite uses temp file + rename pattern (write to .UUID.tmp, rename)
  </behavior>
  <action>
    Add to src/lib/vault.ts:

    1. Add `FileExistsError` class extending VaultError with code 'FILE_EXISTS' and statusCode 409.

    2. Add `resolveWritePath(relativePath: string): Promise<string>` method. Same segment validation as resolvePath (traversal, dotfile checks) but NO fs.lstat/existence check. Throws PathTraversalError on empty path, .., . segments. Throws DotfileAccessError on dot-prefixed segments. Returns resolved absolute path.

    3. Add private `atomicWrite(filePath: string, content: string): Promise<void>` method. Creates temp file as `path.join(dirname, '.' + crypto.randomUUID() + '.tmp')`, writes content, renames to target. Cleans up temp file on error. Import `crypto` from `node:crypto`.

    4. Add `createNote(filePath: string, content: string, frontmatter?: Record<string, unknown>)` method:
       - Call resolveWritePath(filePath)
       - mkdir -p the parent directory (fs.mkdir with recursive: true)
       - Use fs.open(resolved, 'wx') for atomic exclusive create — catches EEXIST to throw FileExistsError
       - Close the file handle from fs.open immediately
       - Assemble content: if frontmatter has keys, use matter.stringify(content, frontmatter); otherwise content + '\n'
       - Call atomicWrite to write the assembled content
       - Return { path: filePath, created: true as const }

    5. Add `updateContent(filePath: string, content: string)` method:
       - Call resolvePath(filePath) — must exist, throws FileNotFoundError if not
       - Call atomicWrite(resolved, content + '\n')
       - Return { path: filePath, updated: true as const }

    6. Add `appendContent(filePath: string, text: string, mode: 'append' | 'prepend')` method:
       - Call resolvePath(filePath) — must exist
       - Read existing file with fs.readFile
       - Parse with gray-matter: const parsed = matter(raw)
       - If mode === 'append': updatedContent = parsed.content.trimEnd() + '\n\n' + text
       - If mode === 'prepend': updatedContent = text + '\n\n' + parsed.content.trimStart()
       - Reassemble with matter.stringify(updatedContent, parsed.data) — preserves frontmatter
       - Call atomicWrite with the reassembled output
       - Return { path: filePath, updated: true as const }

    Add tests to src/lib/__tests__/vault.test.ts in new describe blocks for each method. Use the existing temp directory fixture pattern. Create test files in beforeAll, verify write results by reading files back from disk.
  </action>
