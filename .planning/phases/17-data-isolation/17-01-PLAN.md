  <name>Task 2: Refactor qdrant plugin — user_id index, legacy purge, internalize raw client</name>
  <files>src/plugins/qdrant.ts, src/plugins/__tests__/qdrant.test.ts</files>
  <action>
    Refactor src/plugins/qdrant.ts:

    1. Add 'user_id' keyword index creation OUTSIDE the if (!exists) block (idempotent, same pattern as TEXT_INDEXES):
       ```typescript
       try {
         await client.createPayloadIndex(COLLECTION_NAME, {
           field_name: 'user_id',
           field_schema: 'keyword',
         });
       } catch {
         // Index already exists — safe to ignore
       }
       ```

    2. Add legacy vector purge AFTER index setup:
       ```typescript
       await client.delete(COLLECTION_NAME, {
         filter: {
           must: [{ is_empty: { key: 'user_id' } }],
         },
       });
       ```
       Log at info level: "Purged legacy vectors without user_id"

    3. REMOVE `fastify.decorate('qdrant', client)` — raw client stays local to plugin closure.

    4. Instead, decorate fastify with a factory function for creating tenant clients:
       ```typescript
       import { TenantQdrantClient } from '../lib/tenant-qdrant-client.js';

       declare module 'fastify' {
         interface FastifyInstance {
           createTenantQdrant: (userId: string) => TenantQdrantClient;
         }
       }

       fastify.decorate('createTenantQdrant', (userId: string) => {
         return new TenantQdrantClient(client, userId);
       });
       ```
       Remove the old `FastifyInstance.qdrant` type declaration.

    5. Also expose a `purgeUserVectors(userId: string)` function for user-removed cleanup:
       ```typescript
       declare module 'fastify' {
         interface FastifyInstance {
           purgeUserVectors: (userId: string) => Promise<void>;
         }
       }

       fastify.decorate('purgeUserVectors', async (userId: string) => {
         await client.delete(COLLECTION_NAME, {
           filter: { must: [{ key: 'user_id', match: { value: userId } }] },
         });
       });
       ```

    Update src/plugins/__tests__/qdrant.test.ts:
    - Update tests to verify user_id keyword index is created
    - Add test for legacy vector purge (mock client.delete called with is_empty filter)
    - Update tests to verify fastify.createTenantQdrant exists (not fastify.qdrant)
    - Verify fastify.purgeUserVectors exists
    - Remove any assertions about fastify.qdrant being a QdrantClient
