**qdrant.ts modification:**
1. Export `COLLECTION_NAME` as a named export.

2. Add a `TEXT_INDEXES` array for full-text indexes:
```typescript
const TEXT_INDEXES = ['text', 'title', 'section_path'] as const;
```

3. AFTER the existing `if (!exists)` block (not inside it), add full-text index creation for each field in `TEXT_INDEXES`. Wrap each `createPayloadIndex` call in try/catch to ignore "already exists" errors (idempotent on restart per Pitfall 7 from RESEARCH.md):
```typescript
for (const field of TEXT_INDEXES) {
  try {
    await client.createPayloadIndex(COLLECTION_NAME, {
      field_name: field,
      field_schema: {
        type: 'text',
        tokenizer: 'multilingual',
        lowercase: true,
      },
    });
  } catch {
    // Index already exists — safe to ignore on restart
  }
}
```

This is placed OUTSIDE the `if (!exists)` block so text indexes are created even on existing collections (upgrading from Phase 5).

**Important:**
- Do NOT modify the existing keyword `PAYLOAD_INDEXES` array or the `if (!exists)` block
- The `multilingual` tokenizer handles Russian + English token boundaries (per CONTEXT.md requirement)
- `lowercase: true` for case-insensitive matching (per locked decision)
