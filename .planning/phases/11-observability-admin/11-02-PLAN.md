  <action>
    1. Create `src/features/admin/schemas.ts` with TypeBox schemas:
       - `ReindexRequestBody`: Union of three shapes:
         - `{ scope: 'full' }`
         - `{ scope: 'path', path: string }`
         - `{ scope: 'folder', folder: string }`
       - `ReindexResponse`: `{ jobId: string, status: string, message: string }`
       - `ReindexStatusQuery`: `{ jobId: string }` (query parameter)
       - `ReindexStatusResponse`: `{ jobId: string, status: string, filesProcessed: number, totalFiles: number, errors: string[], startedAt: string, completedAt?: string }`
       - Export route schema objects: `reindexSchema` (body + response 202), `reindexStatusSchema` (querystring + response 200)

    2. Create `src/features/admin/service.ts`:
       - Define `ReindexJob` interface: `{ id: string, scope: 'full' | 'path' | 'folder', status: 'running' | 'completed' | 'failed', filesProcessed: number, totalFiles: number, errors: string[], startedAt: string, completedAt?: string }`
       - Export `ReindexService` class:
         - Constructor takes `fastify: FastifyInstance` (needs indexer, db, vault access)
         - Private `jobs = new Map<string, ReindexJob>()`
         - `createJob(scope, target?)`:
           - For 'full': Check `fastify.indexer.isIndexing` — if true, throw error (caller maps to 409). Call `fastify.indexer.stop()` then `fastify.indexer.start()`. Listen for 'changes' event to track progress and mark job completed.
           - For 'path': Query DB to verify file exists. Emit synthetic updated event by reading the file, computing hash, and emitting `fastify.indexer.emit('changes', [{ type: 'updated', path: target, contentHash }])`. Mark job completed after emit.
           - For 'folder': Query DB for all files matching folder prefix (`LIKE folder%`). Emit batch of synthetic 'updated' events for each file. Mark completed after all emitted.
         - `getJob(id)`: Return job from map or undefined
         - Generate job IDs with `randomUUID()` from `node:crypto`
  </action>
  <verify>
    <automated>pnpm test -- --run src/features/admin/__tests__/routes.test.ts</automated>
  </verify>
  <done>ReindexService creates jobs for all three scopes, tracks progress, prevents concurrent full reindex, stores job state in memory.</done>
</task>
