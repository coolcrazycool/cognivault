3. Auth plugin function:
   - Register `cognivault_auth_failures_total` Counter on `fastify.metrics.promRegistry`
   - Add onRequest hook that:
     a. Skips if `request.routeOptions.config?.skipAuth` is truthy
     b. Skips if `request.url.startsWith('/docs')`

     f. Enriches logging: `request.log = request.log.child({ userId: user.userId })`
   - Error response for ALL failures: `{ error: { code: 'UNAUTHORIZED', message: 'Invalid or missing API key' } }`

4. Export with fp wrapper: `fp(authPlugin, { name: 'auth', dependencies: ['registry', 'metrics'] })`

Run tests — they MUST pass.
