  <action>
    1. Create `src/plugins/sync.ts`:

       **Interface SyncEntry:**
       ```typescript
       interface SyncEntry {
         process: ChildProcess | null;
         backoffDelay: number;
         restartTimer: NodeJS.Timeout | null;
         stopping: boolean;
       }
       ```

       **Constants:** BASE_DELAY=1000, MAX_DELAY=30000, BACKOFF_FACTOR=2, STABILITY_THRESHOLD=60000 (1 min of running = reset backoff), KILL_TIMEOUT=5000

       **Plugin function `syncPlugin(fastify)`:**
       - Create `syncs = new Map<string, SyncEntry>()`
       - Register metrics on `fastify.metrics.promRegistry`:
         - `cognivault_sync_running` Gauge with `user_id` label
         - `cognivault_sync_failures_total` Counter with `user_id` label

       **`startSync(user: UserRecord)` inner function:**
       a. Clean stale lock: `fs.unlink(join(user.vaultPath, '.obsidian', '.sync.lock')).catch(() => {})` (ENOENT safe)
       b. Spawn: `spawn('ob', ['sync', '--continuous'], { cwd: user.vaultPath, env: { ...process.env, OBSIDIAN_AUTH_TOKEN: user.obsidian.token ?? '' }, stdio: ['ignore', 'pipe', 'pipe'] })`
       c. Set `syncRunning.labels({ user_id: user.userId }).set(1)`
       d. Record `startTime = Date.now()` for stability tracking
       e. Pipe stdout/stderr to `fastify.log.info`/`fastify.log.warn` with `{ userId: user.userId, source: 'ob-sync' }` context
       f. On `exit` event:
          - Set gauge to 0
          - If `entry.stopping` return (graceful shutdown)
          - Increment `syncFailures` counter
          - Log exit code with structured context
          - If process ran longer than STABILITY_THRESHOLD, reset backoffDelay to BASE_DELAY
          - Else: `entry.backoffDelay = Math.min(entry.backoffDelay * BACKOFF_FACTOR, MAX_DELAY)`
          - Set restartTimer: `setTimeout(() => startSync(user), entry.backoffDelay)`

       **Registry event handlers:**
       - `user-added`: Create SyncEntry with backoffDelay=BASE_DELAY, call startSync
       - `user-removed`: Set entry.stopping=true, send SIGTERM, setTimeout 5s then SIGKILL, clear restartTimer, delete from map, set gauge to 0

       **onClose hook:** Iterate all entries, set stopping=true, SIGTERM all, clearTimeout all restartTimers, wait 5s, SIGKILL remaining

       **Export:** `fp(syncPlugin, { name: 'sync', dependencies: ['registry', 'metrics'] })`

       - Use `buildApp` with sync plugin (or register sync plugin on a minimal Fastify instance with mocked registry and metrics)

       - Simulate process exit by emitting 'exit' event on the mock ChildProcess
