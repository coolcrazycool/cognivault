  <files>src/lib/vault.ts, src/features/vault/routes.ts, src/features/vault/__tests__/routes.test.ts</files>
  <behavior>
    - readMetadata('note-with-tags-array.md') returns { metadata: { tags: ['a', 'b'] } }
    - readMetadata('note-with-tags-string.md') normalizes tags string to array: { metadata: { tags: ['productivity'] } }
    - readMetadata('note-with-nested.md') preserves nested YAML as nested JSON
    - readMetadata('no-frontmatter.md') returns { metadata: {} }
    - readMetadata('malformed-yaml.md') returns { metadata: {}, warning: 'Failed to parse...' }
    - readMetadata('nonexistent.md') throws FileNotFoundError
    - GET /api/vault/metadata?path=note.md returns 200 with { path, metadata }
    - GET /api/vault/metadata?path=nonexistent.md returns 404
    - GET /api/vault/metadata?path=../../etc/passwd returns 403
    - GET /api/vault/metadata without ?path returns 400
    - GET /api/vault/metadata without auth returns 401
  </behavior>
  <action>
    Update `src/lib/vault.ts` -- implement `readMetadata(filePath: string)`:
    1. Resolve via `resolvePath(filePath)`
    2. Read file with `readFile(resolved, 'utf-8')`
    3. Parse with `matter(fileContent)` inside try/catch
    4. On success: extract `parsed.data` as metadata object
    5. Normalize tags: if `metadata.tags` is a string, wrap in array `[metadata.tags]`. If array, keep. If absent, do not add empty array.
    6. Return `{ path: filePath, metadata }`
    7. On gray-matter error: return `{ path: filePath, metadata: {}, warning: 'Failed to parse frontmatter in {filePath}' }`

    Update `src/features/vault/routes.ts` -- add metadata route:
    1. `GET /metadata` handler: extract query param path (required), call `fastify.vault.readMetadata(path)`, return result
    2. Use `metadataSchema` from schemas.ts for validation
    3. Same error handling pattern as /content route

    Update `src/features/vault/__tests__/routes.test.ts` -- add metadata tests:
    1. Add test fixtures: note with tags array, note with tags string, note with nested YAML, note without frontmatter, note with malformed YAML (e.g., `---\n: invalid\n---`)
    2. Test all behaviors listed above
    3. Verify tags normalization in response JSON
    4. Verify nested objects preserved
    5. Verify warning field present on malformed YAML
  </action>
