### Integration Observations

1. **Folder filter gap in semantic search** — `filters.folder` only post-filtered in `lexical()`, not applied in `semantic()` or hybrid's semantic leg. Documented trade-off with TODO.
2. **Admin reindex status timing** — Job marked 'completed' on `scanComplete` before pipeline queue drains. Polling agents may see stale search results briefly.
3. **Path-scoped reindex contentHash** — Synthetic event emits `contentHash: ''` which gets stored in Qdrant payload instead of real hash.
4. **SQLite not persisted in Docker** — `COGNIVAULT_DATA_DIR=/tmp/cognivault-data` is ephemeral. Full re-index on every container restart while Qdrant data IS persisted.
5. **Private field access via cast** — `VaultManager.rootPath` accessed via `as unknown as { rootPath: string }` in pipeline.ts and indexer.ts.
