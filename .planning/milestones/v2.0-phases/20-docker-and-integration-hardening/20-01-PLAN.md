  <action>
Rewrite the production stage of the Dockerfile:

1. Add tini and obsidian-headless build dependencies after the `FROM node:22-slim AS production` line:
```dockerfile
RUN apt-get update && apt-get install -y --no-install-recommends tini build-essential python3 \
    && npm install -g obsidian-headless \
    && apt-get purge -y build-essential python3 && apt-get autoremove -y \
    && rm -rf /var/lib/apt/lists/*
```
Note: build-essential and python3 are needed for the `btime` native addon in obsidian-headless. They are purged after install to keep the image slim.

2. After the existing `RUN mkdir -p /data && chown node:node /data` line, keep it as-is (already creates /data).

3. Replace the CMD line with ENTRYPOINT + CMD:
```dockerfile
ENTRYPOINT ["/usr/bin/tini", "--"]
CMD ["node", "dist/server.js"]
```

4. Keep the build stage unchanged. Keep corepack enable, pnpm install --frozen-lockfile --prod, COPY dist, COPY drizzle, USER node, EXPOSE 3000 in their existing positions.

If `npm install -g obsidian-headless` fails during the build without build-essential (pure JS fallback works), then remove build-essential and python3 from the apt-get install line to keep image slimmer. Try with build tools first as the safe default.
