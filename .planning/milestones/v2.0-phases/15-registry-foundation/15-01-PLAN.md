<feature>
  <name>UserRegistry — standalone class</name>
  <files>src/lib/user-registry.ts, src/lib/__tests__/user-registry.test.ts</files>
  <behavior>
    ## Schema & Validation
    - Zod schema validates: userId (lowercase alphanumeric + hyphens), apiKey (cv- prefix), vaultPath, openaiKey, obsidian (email, password, vault required; token optional)
    - usersFileSchema is z.array(userRecordSchema)
    - Reject entire file if any entry is invalid (no partial loads)
    - Uniqueness enforced on both userId and apiKey — duplicate of either is a validation error

    ## Construction & Load
    - Constructor accepts { filePath, logger? (Pino-compatible), onReload?, onUserCountChange? }
    - load() reads and parses users.json, populates Maps, throws on malformed (fatal at startup)
    - If file doesn't exist, creates empty [] file and starts with zero users
    - Lookup: getUserByApiKey(key) -> UserRecord | undefined, getUserById(userId) -> UserRecord | undefined
    - getAllUsers() -> UserRecord[], getUserCount() -> number
    - All returned records are deep-frozen copies (Object.freeze outer + obsidian sub-object)

    ## Hot-Reload (TENANT-02)
    - startWatching() uses fs.watch on PARENT DIRECTORY (not file) to detect atomic rename-over
    - Debounce ~500ms via setTimeout/clearTimeout
    - Content hash (SHA-256) comparison — skip reload if hash unchanged
    - On valid reload: update Maps, emit diff events, call onReload('success'), call onUserCountChange(count)
    - On invalid reload: log warning, keep last valid data, call onReload('rejected')
    - Survives file deletion — keeps last valid registry, re-establishes on file reappear
    - stopWatching() cleans up watcher and debounce timer

    ## Events
    - Extends EventEmitter<RegistryEvents>
    - user-added: [user: UserRecord] — new userId in reload
    - user-removed: [user: UserRecord] — userId gone in reload
    - user-updated: [user: UserRecord, previous: UserRecord] — same userId, different content

    ## Write Methods (TENANT-03)
    - addUser(record) — validates, checks uniqueness, updates Maps, atomic writes to disk
    - removeUser(userId) — removes from Maps, atomic writes to disk
    - Atomic write: writeFile to {filePath}.{timestamp}.tmp then rename over original
    - Self-write detection: content hash match after own write skips reload

    ## Static Utility
    - UserRegistry.generateApiKey() — crypto.randomBytes(24).toString('base64url') with cv- prefix

    ## Test Cases
    - Load valid users.json -> getUserByApiKey returns correct user
    - Load valid users.json -> getUserById returns correct user
    - Missing file -> creates empty [], getUserCount() === 0
    - Malformed JSON on startup -> throws Error
    - Valid schema but duplicate userId -> throws Error
    - Valid schema but duplicate apiKey -> throws Error
    - getUserByApiKey returns frozen copy (mutation test)
    - addUser writes atomically (tmp file then rename)
    - addUser with duplicate userId -> throws Error
    - removeUser removes from lookups and writes to disk
    - Hot-reload: write new valid file -> Maps updated, events emitted
    - Hot-reload: write invalid file -> Maps unchanged, onReload('rejected') called
    - Content hash: touch file without changing content -> no reload triggered
    - Diff events: add user -> user-added emitted; remove user -> user-removed emitted; change field -> user-updated emitted
    - generateApiKey() returns string starting with cv-
    - generateApiKey() returns unique values on successive calls
  </behavior>
  <implementation>
    Build src/lib/user-registry.ts following the VaultIndexer pattern (typed EventEmitter, constructor injection, no Fastify dependency).

    Structure:
    1. Zod schemas at top (obsidianSchema, userRecordSchema, usersFileSchema) — export UserRecord type and userRecordSchema
    2. RegistryEvents interface for typed EventEmitter
    3. UserRegistryOptions interface: { filePath: string, logger?: { info, warn, error }, onReload?: (status) => void, onUserCountChange?: (count) => void }
    4. UserRegistry class extends EventEmitter<RegistryEvents>:
       - Private fields: byApiKey Map, byUserId Map, filePath, logger, lastContentHash, watcher, debounceTimer, callbacks
       - deepFreeze helper (freezes outer + obsidian sub-object)
       - async load(): read file (create empty if missing), parse JSON, validate Zod, validate uniqueness, populate Maps
       - getUserByApiKey/getUserById: return deepFreeze'd copy or undefined
       - getAllUsers/getUserCount: array of frozen copies / map size
       - async addUser(record): validate single record, check uniqueness against existing, add to Maps, atomicWrite
       - async removeUser(userId): find and remove from Maps, atomicWrite
       - private async atomicWrite(): serialize users to JSON, writeFile to .tmp, rename over original, update lastContentHash
       - startWatching(): fs.watch on dirname(filePath), filter by basename, debounce 500ms, handleFileChange
       - private async handleFileChange(): readFile, computeHash, compare hash (skip if same), validate, diffUsers, update Maps, emit events
       - private diffUsers(): compare old/new Maps, emit user-added/removed/updated
       - stopWatching(): clearTimeout debounceTimer, close watcher
       - static generateApiKey(): cv- + randomBytes(24).toString('base64url')

    Use .js extensions in all imports (ESM). No default export. Named exports only.
