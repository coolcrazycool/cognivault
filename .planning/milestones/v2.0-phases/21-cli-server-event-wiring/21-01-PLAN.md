<objective>
Add direct event emission to UserRegistry.addUser() and removeUser() so CLI writes immediately propagate lifecycle events, and mark OBS-03 complete.

Purpose: CLI commands write users.json via a separate UserRegistry instance that has no listeners. The server's registry detects the change via fs.watch. By emitting events directly in the write methods, any registry instance (including future server-side admin APIs) will reliably fire lifecycle events without depending on fs.watch timing.

Output: Updated user-registry.ts with direct emit, new tests, OBS-03 marked complete.
</objective>
