  <files>src/lib/vault.ts, src/lib/__tests__/vault.test.ts</files>
  <behavior>
    - resolvePath('notes/test.md') resolves to absolute path within vault root
    - resolvePath('../../etc/passwd') throws PathTraversalError
    - resolvePath('../outside') throws PathTraversalError
    - resolvePath('.obsidian/workspace.json') throws VaultError (dotfile)
    - resolvePath('folder/.hidden/file.md') throws VaultError (dotfolder in middle)
    - resolvePath('') resolves to vault root (for directory listing)
    - resolvePath('path//double//slash') normalizes to 'path/double/slash'
    - resolvePath('/leading/slash') strips leading slash and resolves correctly
    - resolvePath with symlink pointing outside vault throws PathTraversalError
    - resolvePath with Cyrillic path 'Заметки/проект.md' resolves correctly
    - resolvePath with spaces 'My Notes/todo.md' resolves correctly
    - initialize() succeeds when VAULT_PATH is a valid directory
    - initialize() throws when VAULT_PATH does not exist
    - initialize() throws when VAULT_PATH is a file, not a directory
  </behavior>
  <action>
    Install gray-matter: `pnpm add gray-matter`.

    Create `src/lib/vault.ts` with:

    1. Error classes: `VaultError` (base, with code + statusCode), `PathTraversalError` (403, PATH_TRAVERSAL), `FileNotFoundError` (404, NOT_FOUND), `UnsupportedMediaTypeError` (415, UNSUPPORTED_MEDIA_TYPE), `DotfileAccessError` (403, FORBIDDEN).

    2. `VaultManager` class:
       - Constructor takes `rootPath: string` (the resolved absolute path)
       - `initialize()`: verify rootPath exists and is a directory via `stat()`, throw descriptive error if not
       - `resolvePath(relativePath: string)`: normalize path (collapse //, strip leading/trailing slashes), check each segment for leading dot (reject with DotfileAccessError), resolve with `path.resolve(rootPath, normalized)`, verify result starts with `rootPath + path.sep` or equals rootPath (reject with PathTraversalError), then for existing paths check `lstat` for symlink (reject) and `realpath` starts with rootPath (reject). Throw FileNotFoundError on ENOENT.
       - Stub methods (implementation in Plan 02/03): `listFiles(options)`, `readContent(filePath)`, `readMetadata(filePath)` -- define interfaces `VaultEntry`, `ListOptions`, `ContentResult`, `MetadataResult` and export them.

    3. Define and export interfaces: `VaultEntry { name, path, type }`, `ListOptions { path?, recursive?, ext? }`, `ContentResult { path, content }`, `MetadataResult { path, metadata, warning? }`.

    Create `src/lib/__tests__/vault.test.ts` with unit tests using a temporary directory (vitest `beforeAll`/`afterAll` with `fs.mkdtemp`). Create test fixtures: subdirectories, files, a symlink pointing outside, dotfolders. Test all behaviors listed above.

    Use `node:fs/promises` for all filesystem operations. Use `node:path` for path resolution. Use `node:os` for tmpdir.
