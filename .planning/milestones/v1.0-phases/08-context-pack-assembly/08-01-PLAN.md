Define types:
- `SectionName = 'summary' | 'architecture' | 'adrs' | 'glossary' | 'implementation'`
- `AssembleOptions = { tokenBudget: number; minScore: number }`
- `ContextEntry` (matching schema: text, source, section)

Initialize tiktoken encoder at module level: `const enc = getEncoding('cl100k_base');`

Export `countTokens(text: string): number` (public for testing).

Implement `ContextService` class with `assemble(results: SearchResult[], opts: AssembleOptions): ContextPack`:

1. **Score normalization:** Find max score in results. If max > 0, divide all scores by max to normalize to [0,1]. This makes `min_score: 0.3` mean "at least 30% of top relevance" — addressing the RRF raw score range issue (raw RRF max ~0.033 with K=60).

2. **Relevance floor:** Filter results where normalizedScore >= opts.minScore. Track `chunksExcluded = results.length - aboveFloor.length`.

3. **Group by path:** Create `Map<string, { results: SearchResult[], maxScore: number }>`. For each group, sort results by `section_path` lexicographically to approximate document order.

4. **Merge groups:** For each group, merge chunk texts with `\n\n` separator. Count tokens on merged text. Build source metadata: `{ path, title (from first chunk), sections: unique section_paths, score: maxScore }`.

5. **Sort groups by maxScore descending.**

6. **Greedy budget fill:** Iterate sorted groups. For each, if `totalTokens + entryTokens <= tokenBudget`, include it. Otherwise skip (do NOT break — a smaller entry later might fit). Track `chunksIncluded`.

7. **Classify entries:** Apply `classifyEntry(type: string | null, path: string): SectionName`:
   - First check `type` field against TYPE_TO_SECTION map: summary/overview->summary, architecture/arch->architecture, adr/decision->adrs, glossary/definition->glossary
   - Then folder heuristic (case-insensitive path check): /adr or /decisions->adrs, /architecture or /arch->architecture, /glossary or /definitions->glossary, /summary or /overview->summary
   - Default: "implementation"

8. **Build response:** Group entries by section name. Within each section, order by score descending. Only include sections with entries (empty sections omitted). Add meta: `{ total_tokens, token_budget: opts.tokenBudget, chunks_included, chunks_excluded }`.

Note: `query_ms` is NOT set by the service — it's set by the route handler (measures wall time including the hybrid search call).
