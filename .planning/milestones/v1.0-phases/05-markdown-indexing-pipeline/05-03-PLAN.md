  <name>Task 1: Pipeline plugin with create/update event processing</name>
  <files>src/plugins/pipeline.ts, src/plugins/__tests__/pipeline.test.ts, src/app.ts</files>
  <behavior>
    - On 'created' event: reads file content, chunks with chunkMarkdown, embeds with fastify.embedder, upserts to Qdrant with full payload
    - On 'updated' event: same as created + deletes stale vectors where chunk_index >= new chunk count
    - Qdrant upsert payload includes: path, title, chunk_index, section_path, tags, project, status, type, content_hash, extra_metadata
    - Deterministic chunk IDs via UUID v5 of "{file_path}:{chunk_index}"
    - Frontmatter-only notes (empty chunks) skip embedding but still clean up stale vectors
    - embedding_model_version set in indexed_files after successful embedding
    - Partial failure (one file errors) does not block other files in the batch
    - p-queue concurrency limit 3
  </behavior>
  <action>
    1. Create `src/plugins/pipeline.ts` as a Fastify plugin (wrapped with fp):
       - Dependencies: `['indexer', 'qdrant', 'embedder', 'vault', 'db']`
       - Import: `chunkMarkdown` from `../lib/chunker.js`, `v5 as uuidv5` from `uuid`, `PQueue` from `p-queue`, `gray-matter` (matter), `eq` from `drizzle-orm`, `indexedFiles` from `../db/schema.js`
       - Define UUID v5 namespace constant (use DNS namespace: `'6ba7b810-9dad-11d1-80b4-00c04fd430c8'`)
       - Define `chunkId(filePath: string, chunkIndex: number): string` using uuidv5

       - Create `PQueue({ concurrency: 3 })` for note-level parallelism

       - Define `async processCreatedOrUpdated(fastify, event)`:
         a. Read file content via `fastify.vault.readContent(event.path)` — wrap in try/catch, log and skip on error
         b. Parse frontmatter with gray-matter: `const parsed = matter(rawContent)`
         c. Extract title from filename: `path.basename(event.path, '.md')`
         d. Call `chunkMarkdown(parsed.content, { title })` — returns MarkdownChunk[]
         e. If chunks.length === 0 (frontmatter-only), skip embedding but still delete stale vectors for this path
         f. Call `fastify.embedder.embed(chunks.map(c => c.text))` — returns number[][]
         g. Build Qdrant points array:
            ```
            chunks.map((chunk, i) => ({
              id: chunkId(event.path, i),
              vector: embeddings[i],
              payload: {
                path: event.path,
                title,
                chunk_index: i,
                section_path: chunk.sectionPath,
                tags: Array.isArray(parsed.data.tags) ? parsed.data.tags : (typeof parsed.data.tags === 'string' ? [parsed.data.tags] : []),
                project: parsed.data.project ?? null,
                status: parsed.data.status ?? null,
                type: parsed.data.type ?? null,
                content_hash: event.contentHash,
                extra_metadata: JSON.stringify(omit(parsed.data, ['tags', 'project', 'status', 'type'])),
              },
            }))
            ```
         h. Upsert to Qdrant: `fastify.qdrant.upsert('cognivault', { points })`
         i. Delete stale vectors (for 'updated' events or any create that may have old vectors):
            `fastify.qdrant.delete('cognivault', { filter: { must: [{ key: 'path', match: { value: event.path } }, { key: 'chunk_index', range: { gte: chunks.length } }] } })`
         j. Update embedding_model_version in indexed_files:
            `fastify.db.update(indexedFiles).set({ embeddingModelVersion: config.EMBEDDING_MODEL }).where(eq(indexedFiles.path, event.path)).run()`

       - Define `async processDeleted(fastify, event)`:
         a. Delete all vectors matching path: `fastify.qdrant.delete('cognivault', { filter: { must: [{ key: 'path', match: { value: event.path } }] } })`

       - Define `async processMoved(fastify, event)`:
         a. Update path in Qdrant payload: `fastify.qdrant.setPayload('cognivault', { payload: { path: event.path }, filter: { must: [{ key: 'path', match: { value: event.oldPath } }] } })`
         b. Also update title payload: derive new title from `path.basename(event.path, '.md')`

       - Listen to indexer events:
         ```typescript
         const onChanges = (events: FileChangeEvent[]): void => {
           for (const event of events) {
             void queue.add(async () => {
               try {
                 switch (event.type) {
                   case 'created':
                   case 'updated':
                     await processCreatedOrUpdated(fastify, event);
                     break;
                   case 'deleted':
                     await processDeleted(fastify, event);
                     break;
                   case 'moved':
                     await processMoved(fastify, event);
                     break;
                 }
               } catch (err) {
                 fastify.log.error({ event, err }, 'Pipeline processing failed — will retry on next poll');
               }
             });
           }
         };
         fastify.indexer.on('changes', onChanges);
         ```

       - onClose hook: remove listener, drain queue
         ```typescript
         fastify.addHook('onClose', async () => {
           fastify.indexer.removeListener('changes', onChanges);
           queue.clear();
           await queue.onIdle();
         });
         ```

    2. Update `src/app.ts` — add pipeline plugin registration after qdrant:
       ```typescript
       import pipelinePlugin from './plugins/pipeline.js';
       // after qdrant registration:
       await app.register(pipelinePlugin);
       ```

    3. Create `src/plugins/__tests__/pipeline.test.ts`:
       - Mock fastify decorators: vault.readContent, embedder.embed, qdrant.upsert/delete/setPayload, db.update
       - Test created event: verify chunkMarkdown called, embed called with chunk texts, upsert called with correct payload shape
       - Test updated event: verify stale cleanup (delete with chunk_index >= N filter) called after upsert
       - Test deleted event: verify qdrant.delete called with path filter
       - Test moved event: verify setPayload called with new path, embed NOT called
       - Test frontmatter-only note: no embed call, stale cleanup still runs
       - Test partial failure: one event errors, others still processed
       - Test payload includes tags/project/status/type from frontmatter
       - Test extra_metadata contains remaining frontmatter fields as JSON string
