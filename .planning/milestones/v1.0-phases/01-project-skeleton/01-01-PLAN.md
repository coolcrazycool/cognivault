<task type="auto">
  <name>Task 2: Create Fastify app factory, config, error handler, and server entry point</name>
  <files>src/config.ts, src/app.ts, src/server.ts, src/plugins/error-handler.ts</files>
  <action>
1. Create src/config.ts per RESEARCH.md Pattern 3: Zod schema parsing process.env at import time. Fields: PORT (coerce number, default 3000), HOST (string, default 0.0.0.0), LOG_LEVEL (enum of pino levels, default info), COGNIVAULT_API_KEY (string, min 1), VAULT_PATH (string, min 1), QDRANT_URL (string url, default http://localhost:6333). Export both `Config` type and `config` const.

2. Create src/plugins/error-handler.ts: A Fastify plugin wrapped with `fastify-plugin` (fp) that sets a custom error handler. The error handler formats all errors as `{ error: { code: string, message: string } }`. Map Fastify validation errors to code "VALIDATION_ERROR", 401 errors to "UNAUTHORIZED", 404 to "NOT_FOUND", and default to "INTERNAL_ERROR". Use named export: `export default fp(async function errorHandlerPlugin(...))`.

3. Create src/app.ts per RESEARCH.md Pattern 1: Export `buildApp` function. Accept options `{ logger?: boolean | object }`. Create Fastify instance with TypeBoxTypeProvider. Register error-handler plugin. Do NOT register auth plugin yet (that's plan 02). Do NOT register any routes yet (plan 02). Return the app instance. Use `.js` extensions in all imports.

4. Create src/server.ts: Import buildApp and config. Call buildApp with logger true. Call app.listen({ port: config.PORT, host: config.HOST }). Log startup message. Handle SIGTERM/SIGINT for graceful shutdown (app.close()).

IMPORTANT: All imports must use `.js` extension (ESM requirement). Use named exports only (no default exports except for fastify-plugin wrapped plugins where default is the convention). Use `import type` for type-only imports.
