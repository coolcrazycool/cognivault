       - Declare `FastifyInstance` module augmentation: `metrics: { searchDuration, searchRequests, indexQueueDepth, staleVectorCleanups }`
       - Create new Registry (NOT default global — avoids test pollution per research pitfall)
       - Call `collectDefaultMetrics({ register, prefix: 'cognivault_' })`
       - Create Histogram `cognivault_search_duration_seconds` with `labelNames: ['type']`, buckets `[0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1, 2.5]`, registers `[register]`
       - Create Counter `cognivault_search_requests_total` with `labelNames: ['type']`, registers `[register]`
       - Create Gauge `cognivault_index_queue_depth` (no labels), registers `[register]`
       - Create Counter `cognivault_stale_vector_cleanups_total` (no labels), registers `[register]`
       - Decorate fastify with `metrics` object containing all four
       - Register GET `/metrics` route with `{ config: { skipAuth: true } }`, handler returns `register.metrics()` with correct content-type header
       - Export as `fp(metricsPlugin, { name: 'metrics', dependencies: [] })`

    4. Register metrics plugin in `src/app.ts` after toonPlugin, before infrastructure plugins:
