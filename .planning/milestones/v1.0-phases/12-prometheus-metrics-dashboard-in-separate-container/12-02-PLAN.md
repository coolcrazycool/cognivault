  <name>Task 1: Create Prometheus config and alert rules</name>
  <files>monitoring/prometheus/prometheus.yml, monitoring/prometheus/rules/cognivault.yml</files>
  <action>
Create the monitoring/ directory structure.

1. Create `monitoring/prometheus/prometheus.yml`:
   ```yaml
   global:
     scrape_interval: 15s
     evaluation_interval: 15s

   rule_files:
     - /etc/prometheus/rules/*.yml

   scrape_configs:
     - job_name: cognivault
       static_configs:
         - targets: ['cognivault:3000']
       metrics_path: /metrics
   ```

2. Create `monitoring/prometheus/rules/cognivault.yml` with 4 alert rules:
   - `CogniVaultDown`: `up{job="cognivault"} == 0` for 1m, severity critical
   - `HighSearchLatencyP99`: `histogram_quantile(0.99, sum(rate(cognivault_search_duration_seconds_bucket[5m])) by (le, type)) > 2` for 5m, severity warning
   - `HighMemoryUsage`: `process_resident_memory_bytes{job="cognivault"} > 512 * 1024 * 1024` for 5m, severity warning (512 MiB threshold)
   - `HighErrorRate`: `sum(rate(cognivault_http_request_duration_seconds_count{status_code=~"5.."}[5m])) / sum(rate(cognivault_http_request_duration_seconds_count[5m])) > 0.05` for 5m, severity warning. Note: if prom-client collectDefaultMetrics does not produce per-status HTTP metrics, use a simpler approach: alert on zero `up` or on search-specific errors. Claude's discretion on the exact PromQL for error rate given available metrics.
  </action>
  <verify>
    <automated>test -f monitoring/prometheus/prometheus.yml && test -f monitoring/prometheus/rules/cognivault.yml && echo "OK"</automated>
  </verify>
  <done>Prometheus config scrapes cognivault:3000/metrics every 15s. Four alert rules defined with appropriate thresholds and durations.</done>

<task type="auto">
  <name>Task 2: Add Prometheus, Grafana to docker-compose and create Grafana provisioning</name>
  <files>docker-compose.yml, monitoring/grafana/provisioning/datasources/prometheus.yml, monitoring/grafana/provisioning/dashboards/dashboards.yml</files>
  <action>
1. Update `docker-compose.yml` — add healthcheck to cognivault service:
   ```yaml
   healthcheck:
     test: ["CMD", "node", "-e", "require('http').get('http://localhost:3000/health', r => process.exit(r.statusCode===200?0:1)).on('error',()=>process.exit(1))"]
     interval: 10s
     timeout: 5s
     retries: 5
   ```
   Use node-based healthcheck because node:22-slim may not have wget/curl.

2. Add `prometheus` service to docker-compose.yml:
   ```yaml
   prometheus:
     image: prom/prometheus:v3.10.0
     command:
       - '--config.file=/etc/prometheus/prometheus.yml'
       - '--storage.tsdb.retention.time=7d'
       - '--storage.tsdb.path=/prometheus'
     ports:
       - "9090:9090"
     volumes:
       - ./monitoring/prometheus:/etc/prometheus:ro
       - prometheus_data:/prometheus
     depends_on:
       cognivault:
         condition: service_healthy
     healthcheck:
       test: ["CMD-SHELL", "wget -qO- http://localhost:9090/-/healthy || exit 1"]
       interval: 10s
       timeout: 5s
       retries: 5
   ```

3. Add `grafana` service to docker-compose.yml:
   ```yaml
   grafana:
     image: grafana/grafana:12.3.2
     ports:
       - "3001:3000"
     environment:
       - GF_AUTH_ANONYMOUS_ENABLED=true
       - GF_AUTH_ANONYMOUS_ORG_NAME=Main Org.
       - GF_AUTH_ANONYMOUS_ORG_ROLE=Viewer
       - GF_AUTH_DISABLE_LOGIN_FORM=true
       - GF_SECURITY_ADMIN_PASSWORD=admin
     volumes:
       - ./monitoring/grafana/provisioning:/etc/grafana/provisioning:ro
       - ./monitoring/grafana/dashboards:/var/lib/grafana/dashboards:ro
       - grafana_data:/var/lib/grafana
     depends_on:
       - prometheus
   ```

4. Add named volumes `prometheus_data` and `grafana_data` to the top-level `volumes:` block.

5. Create `monitoring/grafana/provisioning/datasources/prometheus.yml`:
   ```yaml
   apiVersion: 1
   datasources:
     - name: Prometheus
       type: prometheus
       access: proxy
       uid: prometheus
       url: http://prometheus:9090
       isDefault: true
       editable: false
   ```

6. Create `monitoring/grafana/provisioning/dashboards/dashboards.yml`:
   ```yaml
   apiVersion: 1
   providers:
     - name: CogniVault
       orgId: 1
       type: file
       disableDeletion: true
       updateIntervalSeconds: 30
       allowUiUpdates: false
       options:
         path: /var/lib/grafana/dashboards
   ```
