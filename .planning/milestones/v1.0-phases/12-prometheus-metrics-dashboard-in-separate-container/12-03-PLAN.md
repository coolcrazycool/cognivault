Panel layout (use rows to organize):

**Row 1: HTTP Overview** (collapsed=false)
- Panel: Total Requests (stat panel) — `sum(increase(cognivault_search_requests_total[1h]))`
- Panel: Status Code Breakdown (piechart or stat) — show search request counts by type
- Panel: Avg Response Time (stat panel) — `rate(cognivault_search_duration_seconds_sum[5m]) / rate(cognivault_search_duration_seconds_count[5m])`

**Row 2: Search Latency**
- Panel: Latency p50/p95/p99 by search type (timeseries) — three queries using `histogram_quantile(0.5|0.95|0.99, sum(rate(cognivault_search_duration_seconds_bucket[5m])) by (le, type))`, legend format `{{type}} p50|p95|p99`
- Panel: Latency Heatmap (heatmap panel) — `sum(increase(cognivault_search_duration_seconds_bucket[$__interval])) by (le)`, format "Time series buckets", legend `{{le}}`

**Row 3: Request Volume**
- Panel: Request Rate by Type (timeseries) — `sum(rate(cognivault_search_requests_total[5m])) by (type)`, legend `{{type}}`
- Panel: Request Volume Heatmap (heatmap) — `sum(increase(cognivault_search_requests_total[$__interval])) by (type)`, visualize request density over time
- Panel: Error Rate (timeseries or stat) — use available metrics to show error signal (search request failures if trackable, otherwise omit and add a text annotation panel noting HTTP error metrics are not yet available)

Use gridPos to arrange panels in a 24-column grid. Stat panels: 8 wide. Timeseries: 12 wide. Heatmaps: 12 wide. Height 8 for timeseries/heatmaps, 4 for stats.
