    - moveNote("old.md", "existing.md") throws FileExistsError (destination exists)
    - moveNote("missing.md", "new.md") throws FileNotFoundError (source missing)
    - moveNote("old.md", "deep/nested/new.md") auto-creates destination directories
    - moveNote source must be a file (not directory)
    - DELETE /api/vault/content with body { path } returns 200 + { path, deleted: true }
    - DELETE /api/vault/content with missing path returns 404
    - POST /api/vault/move with body { from, to } returns 200 + { from, to }
    - POST /api/vault/move with existing destination returns 409
  </behavior>
  <action>
    **VaultManager methods (src/lib/vault.ts):**

    1. `deleteNote(filePath: string)`:
       - Call resolvePath(filePath) — must exist, throws FileNotFoundError if not
       - Verify stat.isFile() — if directory, throw FileNotFoundError with message "Not a file: {filePath}"
       - Call fs.unlink(resolved)
       - Return { path: filePath, deleted: true as const }

    2. `moveNote(from: string, to: string)`:
       - Call resolvePath(from) — source must exist
       - Verify source stat.isFile() — reject directories
       - Call resolveWritePath(to) — validate destination path segments
       - Check destination existence with fs.stat — if exists, throw FileExistsError(to)
       - Call fs.mkdir(path.dirname(destResolved), { recursive: true }) — auto-create dirs
       - Call fs.rename(sourceResolved, destResolved)
       - Return { from, to }

    **TypeBox schemas (src/features/vault/schemas.ts):**

    1. `DeleteNoteBodySchema` — Type.Object({ path: Type.String({ minLength: 1 }) })
    2. `DeleteNoteResponseSchema` — Type.Object({ path: Type.String(), deleted: Type.Literal(true) })
    3. `MoveNoteBodySchema` — Type.Object({ from: Type.String({ minLength: 1 }), to: Type.String({ minLength: 1 }) })
    4. `MoveNoteResponseSchema` — Type.Object({ from: Type.String(), to: Type.String() })
    5. Route schema objects: deleteNoteSchema (body + response 200/403/404), moveNoteSchema (body + response 200/403/404/409)
    6. Export Static types for body schemas.

    **Route handlers (src/features/vault/routes.ts):**

    1. DELETE /content handler: extracts path from body, calls fastify.vault.deleteNote(path), replies 200.
    2. POST /move handler: extracts from, to from body, calls fastify.vault.moveNote(from, to), replies 200.
    3. Both use handleVaultError for error mapping.
