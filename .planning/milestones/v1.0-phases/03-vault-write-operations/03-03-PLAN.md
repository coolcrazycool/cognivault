    **VaultManager method (src/lib/vault.ts):**

    Add `updateMetadata(filePath: string, updates: Record<string, unknown>)`:
    - Call resolvePath(filePath) — must exist
    - Read file with fs.readFile(resolved, 'utf-8')
    - Parse with gray-matter: const parsed = matter(raw)
    - Shallow merge: const merged = { ...parsed.data }
    - For each entry in updates: if value === null, delete merged[key]; else merged[key] = value
    - Reassemble: matter.stringify(parsed.content, merged)
    - Call atomicWrite with reassembled content
    - Return { path: filePath, metadata: merged }
