Update the `test` and `test:watch` scripts in package.json to use Node.js `--env-file=.env` flag, which loads the `.env` file before vitest runs. This ensures OPENAI_API_KEY and other env vars are available to the embedding plugin's validate() call during test suite setup.

Current scripts:
```json

"test:watch": "vitest",
```

Updated scripts:
```json

```

Note: `--env-file` is a Node.js v20+ flag. The project uses Node.js v22 LTS, so this is safe. The `dev` script already uses this pattern (`node --env-file=.env --watch dist/server.js`), establishing project precedent.

Alternative if vitest supports it directly: Check if vitest has a `--env-file` or `dotenv` config option. If `vitest run` can be invoked with env loading natively, prefer that over the `node` wrapper. However, vitest does not natively load `.env` files without a plugin, so the `node --env-file` approach is the most reliable.
